# Общие эффекты грязи колёс

VehiclePhysicsProfile.wheelEffects назначает VehicleWheelEffectsProfile.
VehicleWheelEffects работает с фактическим числом колёс VehiclePhysics;
отдельного контроллера Pajero нет. Профиль текущей машины:
Assets/Game/VFX/Mud/Mud wheel effects.asset.

Физика передаёт контакт, нормаль, forwardDir повёрнутого колеса и разницу
окружной скорости шины и скорости кузова в точке контакта. На ведущих колёсах
при slip и газе выбрасываются вращающиеся объёмные комья; на Mud дополнительно
летят вытянутые мокрые капли. Лёд/снег не запускают грязь. Сухая исходная
грунтовая дорога даёт только более мелкие комья. Это визуальная калибровка,
а не гидродинамический расчёт жидкости.

ParticleSystem использует мировые координаты, гравитацию и столкновения с
поверхностями. colliderForce=0: эффекты не меняют силы машины. При попаданиях
создаются ограниченные по частоте пятна на реальном коллайдере, включая кузов.
Пятна следуют Transform объекта; они не являются полноценной проекцией на
криволинейную поверхность и не покрывают весь кузов накопительным слоем грязи.
Пул: 96 пятен, срок 75 с с затуханием; данные не сохраняются между запусками.
При уничтожении секции её дочерние пятна исчезают, слоты создаются заново при
использовании. Существующий AuthoredForestRoute переносит мировые частицы
при floating origin, пятна перемещаются с родительскими объектами.

Все ставки выброса, размеры, цвета, ресурсы, срок пятен и бюджеты вынесены в
SO. Стандартный бюджет на слой/колесо — 384 частицы. Компонент отключает свои
частицы и пятна при OnDisable и уничтожает созданные ресурсы при OnDestroy.

Бесплатные маски Kenney CC0 и атрибуция текстуры SPLEEN VISION перечислены в
Assets/Game/VFX/Mud/SOURCES.txt. Picster не использован: проверенные изображения
оказались световыми узорами. Материал комьев использует карты из нового
пользовательского tire-tracks-in-mud.zip. Покупок и платных пакетов нет.

Новые пользовательские сканы находятся в Assets/Game/Art/RoadScans: исходные
модели/UV/карты сохранены, импорт текстур ограничен 2048. Это библиотека для
следующей сборки связной дороги; импорт сам по себе не заменяет прямоугольные
участки в сцене и не меняет исходную геометрию леса. Лицензию дополнительного
traktore-markak требуется установить перед распространением.

Проверки Unity 6000.6.7f1 / URP 17.6:

- recompile без ошибок; WetMud.shader компилируется без сообщений.
- ValidateMudWheelEffects: 4 колеса, два слоя на колесо; нулевой slip/газ без
  выброса; слабый/сильный slip дал 4/30 частиц; поворот и задний ход изменили
  среднюю скорость выброса по X с -4.65 на +5.93 м/с в финальном прогоне;
  на сухом нет мокрого слоя.
- Реальное падение частиц на тестовый коллайдер создало 48 пятен, связанных
  с его Transform. Тестовый коллайдер и его пятна удалены после проверки.
- CaptureMudWheelEffects — отдельная постановочная проверка отображения;
  направление/газ задаются инструментом, это не доказательство проезда грязи.
- ValidateActualMudDrive: 4 грязевых контакта, slip 11.4 м/с, 34.33 м за 9 с,
  колея .041 м; 500 независимых лучей, расхождение render/collider .00002 м.
  Глубокое копание .381 м без невидимой подстилающей дороги.

После импорта модели без исходных normals Unity пересчитал автоматически
(предупреждения импорта). Также остался сетевой warning Unity AI Account API;
ошибок компиляции/исполнения после исправления и повторных проверок нет.

Команды: unity command script run --file AgentScripts/ValidateMudWheelEffects.cs
--timeout 40; для первоначальной настройки в Edit Mode ConfigureMudWheelEffects.
Standalone-сборка и производительность на целевом ПК не проверены.
