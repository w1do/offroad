# Лужи и брызги

Ниже сохранено описание первой итерации. Актуальное покрытие всей дороги,
чаши луж, смесь трёх выбранных материалов и результаты последних проверок:
[0007 — покрытие и непрерывная колея](../decisions/0007-road-materials-and-continuous-ruts.md).

Используется выбранный пользователем Brown Mud 03 (Rob Tuytel, Poly Haven,
CC0): https://polyhaven.com/a/brown_mud_03. Карты и источник находятся в
Assets/Game/Art/Puddles. Diffuse и normal подключены к существующему смешиванию
грязи; diffuse также виден через мелкую воду. Родные текстуры и UV лесной
дороги сохраняются по краям участков. Исходные FBX не менялись.

ConfigureRealisticPuddles строит горизонтальную воду по реальным впадинам
сканированного дорожного меша. Треугольники обрезаются по высоте воды,
профиль задаёт заполнение 0,035 или 0,17 м над нижней точкой. Мелкие участки
и разливы различаются естественной формой впадин; крупнейший в текущей
сцене имеет габариты около 9,4 × 3,3 м. Это не площадь сплошной воды.
Дорога и её коллайдеры не поднимаются. Вода имеет только trigger-объём,
а её глубина проверяется по тому же мешу, который видит игрок.

Настройки: Assets/Game/Configs/Puddles/Puddle effects.asset. Профиль назначен
общему VehiclePuddleSplash на активной машине, число колёс берётся из
VehiclePhysics. Компонент не прикладывает силы: водные силы остаются у
VehicleWaterInteraction. Выброс зависит от скорости относительно воды и
погружения колеса, работает при движении накатом и задним ходом. Капли летят
в обе стороны, движутся под гравитацией, затухают и сталкиваются без передачи
силы машине. Бюджет — 300 частиц на колесо, до 180 частиц/с на колесо.
Стоянка и сухой грунт не создают водные брызги. Круги на воде остаются у
WaterRippleRenderer. Существующий floating origin переносит мировые частицы.

Материал Game/Forest Puddle использует карту нормалей исходных луж,
две скорости мелкой ряби, отражения окружения, блик, Fresnel и плавный
прозрачный край по глубине. Новые planar/SSR renderer features не добавлялись.

Модули получают воду через исходные prefab, а не через независимые копии
настроек в сцене. Скрипт повторно запускается только в Edit Mode:

```
unity command script run --file AgentScripts/ConfigureRealisticPuddles.cs --entry ConfigureRealisticPuddles.Main --project-path E:/Unity/Test --json
unity command script run --file AgentScripts/ValidateRealisticPuddles.cs --entry ValidateRealisticPuddles.Main --project-path E:/Unity/Test --json
```

Проверено Unity 6000.6.7f1 / URP 17.6: компиляция без ошибок и предупреждений;
shader без ошибок; Edit Mode — 979 проб поверхности; Play Mode — 2364 пробы,
нулевой выброс при стоянке, 112 капель при тестовом накате 6 м/с, выброс на
заднем ходу, отдельно одно мокрое колесо и прекращение выброса на сухом.
Отчёт: work/puddle-validation.txt. Проверка использует временную копию
машины и заданную скорость в отдельном тестовом объёме; это не полный
физический проезд через реальную лужу. Сделаны и просмотрены снимки сцены.

Ограничения: вода визуальная, без динамической симуляции объёма, течения
между колеями и перетекания при деформации дна. Уровень воды фиксирован в
модуле; площадь разлива не пересчитывается по выкопанным колеям. Баллистические
капли не являются полной симуляцией жидкости. Полный игровой проезд,
самостоятельная сборка и замер GPU/CPU не выполнялись.
