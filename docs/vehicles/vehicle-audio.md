# Общий звук машины

`VehicleAudio` — один общий компонент для всех машин, `VehicleAudioProfile` —
отдельный ScriptableObject каждой модели. Они заменяют TruckAudio/TruckAudioProfile
с сохранением GUID .meta и MovedFrom, чтобы старые сцены не потеряли ссылки.
У архивных профилей без engineBands остаётся прежний двухслойный режим.

Компонент читает EngineRpm и EngineLoad из VehiclePhysics. EngineLoad — отношение
положительного момента сцепления к доступному моменту двигателя; это телеметрия,
новых сил звуковая система не добавляет. Высота тона не вычисляется из скорости
кузова: пробуксовка и перегазовка в нейтрали слышны при неподвижной машине.

Для новой машины:

1. Добавить VehicleAudio к корню с VehiclePhysics.
2. Создать Game / Vehicles / Audio profile и назначить компоненту.
3. Задать engineBands в порядке возрастания referenceRpm: название, coast,
   loaded, gain. Клипы должны быть зациклены и настроены на опорные обороты.
4. Настроить громкость, сглаживание RPM/нагрузки, положение и пространственность
   источника, дистанции и допустимый pitch. Для отсутствующих дополнительных
   источников компонент создаёт AudioSource автоматически при включении;
   если профиль назначается кодом после AddComponent, настроить неактивный
   объект и затем активировать его.
5. При необходимости назначить engineStart, шины, цепи, переключения и сигнал.
   brakeAir используется только для машин с соответствующим оборудованием.

Два соседних диапазона плавно смешиваются по квадратному корню веса. Каждый
диапазон имеет варианты под нагрузкой и без газа; RPM и нагрузка сглаживаются
раздельно. Pitch ограничен профилем. При смене передачи обороты следуют физике,
а механический щелчок воспроизводится один раз на изменение передачи.
Количество осей не зашито в аудиокомпонент. Доступные legacy-поля источников
сохранены для архивной машины и старых инструментов.

## Pajero V6

Профиль: Assets/Game/Audio/PajeroV6/Pajero V6 Audio.asset.
Пять диапазонов: 850, 1500, 3000, 4500 и 6500 об/мин; 10 петель coast/load
и отдельная запись запуска. На активной машине дизельные петли выключены,
звук пневматического тормоза отсутствует.

Основа — записи бензинового 3.2L V6 V-Tec EvanBoyerman с Freesound, CC BY 4.0.
Это НЕ проверенная запись Mitsubishi 6G72/6G74: характер другого бензинового
V6 адаптирован для прототипа. Использованы доступные публичные HQ MP3-версии,
не оригинальные lossless-файлы. Числа RPM — калибровочные оценки. Coast-варианты
получены фильтрацией записей; отдельной записи сброса на каждом диапазоне нет.
Полный источник, лицензия и изменения: Assets/Game/Audio/PajeroV6/SOURCES.txt.
Атрибуция также находится в Assets/StreamingAssets/ThirdPartyAudioNotices.txt,
чтобы Unity включал её в сборку. Исходники: SourceAssets/Audio/V6.
Повторяемая обработка: python AgentScripts/PrepareV6Audio.py (numpy/scipy/soundfile).

## Проверка

Unity 6000.6.7f1, CLI 1.0.0-beta.14:

- unity recompile — без ошибок.
- unity command script run --file AgentScripts/ValidateVehicleV6Audio.cs --timeout 40
  — Play Mode, проверка декодирования десяти петель без клиппинга, фактического
  DSP-выхода, увеличения и уменьшения RPM, включения верхнего диапазона,
  отсутствия параллельного дизельного звука и пневмотормоза.
- Получено 822 → 6823 → 822 об/мин; минимальный RMS файлов .140,
  громкость верхнего диапазона .659; DSP и кадры продвигаются.

Это проверка импорта, смешивания и декодированного выхода источников;
прослушивание пользователем на его аудиосистеме и standalone-сборка отдельно
не проверены. Физические настройки тяги, сцепления и трасса этим изменением
не меняются.
