# Аудит фризов, памяти и жизненного цикла — 30.10.2026

Проверены прикладной runtime в Assets/Game/Runtime, старые игровые скрипты
Assets/MountainDrive/Scripts, активная MountainPass и циклы создания/удаления
машины и дорожных модулей. Unity Editor 6000.6.7f1, установленный Unity CLI.
Это аудит прототипа в Editor, не сертификация всей игры и не замер standalone.

## Подтверждённые проблемы и исправления

| Проблема | Исправление / проверяемый результат |
| --- | --- |
| После перезагрузки C# менеджер AuthoredForestRoute терял несерилизуемый lookup loaded, а созданные GameObject оставались. Следующий Update строил мир повторно. | Сериализуемая идентичность AuthoredForestBlockInstance, восстановление lookup из прямых дочерних модулей. Прогресс каждой ветви сохраняется отдельно на время reload. Подтверждённые дубли удалены; при выборе сохранён экземпляр с большей колеёй или активным якорем лебёдки. На пике было 4990 пар дорожных мешей, после очистки — 1220. |
| История протектора сохраняла по 256 КиБ RGBA на затронутый участок; история грунта — три полных массива float. Это намеренная история рейса, но её несжатый рост мог исчерпать память. | Сжатие Deflate/Fastest без потерь, временные буферы из ArrayPool. Память сохраняет все следы текущего рейса. Тестовая разреженная история: грунт 196608 → 2096 байт, маска 262144 → 1253 байта; точное восстановление. Эти коэффициенты относятся к тестовому рисунку, не гарантируются для полностью изрытой дороги. |
| Дорожный MeshCollider получал полную копию render mesh с UV, нормалями и тангентами. | Новые collision mesh содержат позиции и индексы. На реальном модуле из 35 участков: 12809824 → 3168724 байт по сравнению с полным клоном. Поверхность и треугольники совпадают; корректировка winding сохранена. Уже загруженные старые коллайдеры обновятся при обычной выгрузке/создании, принудительная массовая пересборка под игроком не выполнялась. |
| HDR куб неба хранился в несжатом формате. | BC6H на поддерживаемой DX12-системе: 536937440 → 67175568 байт. Размер граней остаётся 2048×2048, исходный HDR не менялся. BC6H — сжатие изображения, в отличие от точного сжатия физической истории. |
| Расчёт огибающей колеса повторял фильтрацию одних коллайдеров для каждой пробы. | Кэш фильтрации живёт только в одном Prepare; физическая сцена/слой разрешаются один раз; центральная проба переиспользуется. Количество проб и настройки не снижены. Парные микрозамеры показывают уменьшение стоимости; результаты опоры совпали. |
| Стриминг создавал HashSet и List каждый Update. | Коллекции wanted/pendingRemoval переиспользуются. |
| В старом отключённом LongRouteStream при уничтожении всей сцены могли остаться созданные native Mesh последнего окна. | RuntimeMeshOwner на каждом вновь генерируемом меше освобождает ресурс при уничтожении его корня. Старый ландшафт не включался. |
| История грунта копировалась повторно в OnDisable и OnDestroy. | Повторное сохранение при уничтожении пропускается. Уплотнение сохраняется и при восстановленной глубине; для полностью пустого состояния удаляется устаревшая запись. |
| Маска протектора считалась dirty даже при записи тех же пикселей. | Повторная неизменяющая запись не инициирует загрузку текстуры. При отключении уничтоженная маска заменяется общей blackTexture в property block, CPU pixels освобождаются. |
| Сценарии проверки могли писать искусственную колею в настоящие route/* ключи текущего рейса. | Проверки стриминга/ресурсов используют уникальные test/* ключи и очищают собственную историю. |

При проверке очистки маски была допущена промежуточная ошибка SetTexture(null):
этот API выбрасывает ArgumentNullException. Исправлено на общую blackTexture.
Финальный сценарий жизненного цикла перехватывает Error/Exception в Unity,
а не только исключение из своего Main. Исторические логи не очищались.

## Выполненные проверки

- Компиляция финального runtime: без ошибок и предупреждений.
- ValidateRouteReloadLifecycle: три цикла потери lookup/пересоздания records;
  те же 24 экземпляра, те же дочерние объекты, прогресс и колея сохранены.
- ValidateRuntimeResourceCycles: три цикла машины и настоящего модуля;
  проверены 436 созданных native ресурсов после deferred Destroy — выживших нет;
  ошибок жизненного цикла в финальном прогоне нет.
- ValidateStreamedMudPersistence: реальный модуль уничтожен и создан снова;
  колея 0,264 → 0,264 м, протектор сохранён точно; используется отдельная test-история.
- ValidateSurfacePacking: точный round trip float/Color32, отклонение другого размера;
  прогретая упаковка тестовых грунта и маски около 1,18 мс. Холодный JIT вынесен
  в BeforeSceneLoad, чтобы не платить его впервые при выгрузке на ходу.
- ValidateColliderMeshMemory: геометрия render/collision совпала, UV в коллайдере нет.
- ValidateSurfaceVisualLifecycle: три повторных включения, маска сохранена,
  property block восстановлен, пул кругов на воде сбрасывается.
- ValidateDeformableMud: независимые render/collision rays совпали;
  естественный крен 6,6°, снижение кузова 0,045 м; следы пережили пересоздание
  и перенос начала координат; давление уменьшило продавливание.
- ValidateLongitudinalClimb: PASS после изоляции фиксированного радиуса этого
  сценария от отдельно проверяемого смятия шины. Проверка радиуса/массы сохранена.
- ValidateShoulderArticulation: PASS.
- InspectRuntimeIntegrity: 7160 объектов текущей сцены; Missing Script не найден;
  один активный VehiclePhysics, профиль валиден, старый контроллер одновременно
  не включён, активных дубликатов ключей модулей нет.
- Game view после BC6H осмотрен: окружение и небо отображаются.

Исходный профиль CPU показал высокую стоимость VehiclePhysics.FixedUpdate.
Паузы EditorLoop от CLI/перекомпиляции нельзя выдавать за обычные игровые фризы.
Парные сравнения огибающей проводились при одинаковой позе в одном callback;
полный FPS по этому микрозамеру не вычислялся.

## Память и ограничения вывода

JSON-снимки содержат **память всего Editor**, импортированные ассеты и caches,
а не только активную сцену. В пиковом снимке Unity allocated около 10,20 ГБ,
managed около 3,12 ГБ; после удаления дублей — около 8,60 и 0,82 ГБ соответственно.
Это не строго контролируемый before/after standalone: между снимками работали
редактор, GC, тесты и стриминг. Счётчики и состав объектов важнее разницы общего числа.

Reserved остаётся около 17,68 ГБ: аллокатор Unity может удерживать освобождённые
пулы, поэтому это число само по себе не доказывает утечку. Принудительный GC или
Resources.UnloadUnusedAssets каждый кадр не добавлялись. В снимках нет
неиспользуемых render/collision mud mesh; проблема дублей была в живых объектах
сцены, которые потерял менеджер, а не в бесхозных Mesh.

История грунта намеренно растёт по мере исследования. Теперь она сжата, но
жёсткого предела памяти и хранения на диске нет; удалять старые следы ради лимита
без изменения требований нельзя. Полностью изрытая трасса сживается хуже теста.

Остались непроверенными: непрерывный полный рейс 100 км, длительное измерение
standalone/VRAM на согласованном ПК, внутренние caches Unity/URP/AI-пакетов,
крайние случаи всех переключений оборудования. Создание модуля и cooking
коллайдеров пока синхронны; редкие рывки на границах требуют отдельного замера
во время длинной поездки. Нельзя утверждать, что устранены все возможные фризы.

## Артефакты

- runtime-memory-cycles.json — освобождение native ресурсов.
- route-reload-lifecycle.json — отсутствие размножения мира.
- runtime-integrity.json — целостность сцены/владение физикой.
- sky-memory.json, collider-mesh-memory.json, surface-cache-memory.json — замеры.
- memory-owners-before.json, memory-owners-peak.json, memory-owners-after.json — снимки.
- wheel-support-performance.json — парное сравнение контактов.

Запуск: `unity command script run --file AgentScripts/ValidateRouteReloadLifecycle.cs --entry ValidateRouteReloadLifecycle.Main --project-path E:/Unity/Test --json`.
Для native-циклов запустить ValidateRuntimeResourceCycles.Main, дать игре кадр
для deferred Destroy, затем ValidateRuntimeResourceCycles.Complete.
