# День, ночь и визуальная погода

Дата: 30.10.2026. Рабочее решение прототипа по запросу пользователя.

В MountainPass добавлен ForestDayNightWeather. Профиль настроек:
`Assets/Game/Configs/Weather/Forest weather.asset`.
Старт в 09:00, сутки за 48 реальных минут. Это калибровка, не требование пользователя.
Во время Play Mode поле hour меняет время; контекстное меню компонента содержит
Preview / Noon, Preview / Midnight, Weather / Clear и Weather / Rain.
Automatic Weather выбирает цели по seed каждые 240 секунд; переход занимает 30 секунд.
Время зависит от игрового deltaTime и останавливается при паузе симуляции.

Один компонент управляет направленным источником света, небом, рассеянным светом
и туманом. Ночью тот же источник представляет противоположный лунный свет.
Солнечная траектория замкнута через полночь; переход интенсивности сумерек плавный.
Небо использует собственный URP shader: солнечный и лунный диски, звёзды,
движущийся слой облаков. Это лёгкая плоская модель облачного слоя, не объёмный рендеринг.
Исходный Spruit Sunrise остаётся статичным небом сцены вне игры и восстанавливается
при отключении компонента. Лес, дорога, материалы и физика машины не заменены.

Дождь — локальный ParticleSystem над камерой, максимум 4000 частиц, мировые
координаты, ограниченное время жизни, исчезновение при столкновении с поверхностью.
Collision Low имеет ограничения точности; эффект не гарантирует отсутствие капель
в любой закрытой геометрии. Частицы не прикладывают силы. При дожде плавно
уменьшается emission существующего снега. Изменений сцепления, грязи, луж,
температуры и экономики нет. Звуки дождя и фары этим изменением не добавлены.
Отражения меняют интенсивность; динамические cubemap окружения не пересчитываются.
Погода воспроизводима по seed при одинаковом ходе симуляции, но пока не сериализуется
в сохранение рейса. Производительность на целевом ПК не измерена.

## Воспроизведение проверки

Unity CLI 1.0.0-beta.14, Unity Editor 6000.6.7f1, URP 17.6.0.
Использован существующий подключённый Editor, без второго процесса импорта.
Синтаксис подтверждён справкой CLI и реестром команд установленного Pipeline 0.9.1.

```powershell
unity recompile --project-path E:/Unity/Test --json
unity command editor.playmode stop --json
unity command script run --file AgentScripts/ConfigureForestWeather.cs --entry ConfigureForestWeather.Main --project-path E:/Unity/Test --json
unity command script run --file AgentScripts/ValidateForestWeather.cs --entry ValidateForestWeather.Main --project-path E:/Unity/Test --json
```

Проверка рендерит 06:00, 12:00, 18:00 и 00:00 в `work/weather`, проверяет ссылки,
ошибки шейдера, разницу интенсивности света, переход 25:00 → 01:00,
бюджет частиц, отсутствие изменения общего профиля и восстановление окружения.
Для runtime-проверки: Play Mode, SetWeather(1,1), дождаться перехода, затем
запустить CaptureForestWeatherRuntime.Main аналогичной командой script run.
Отчёт: `docs/reports/forest-weather.json`, снимок: `work/weather/runtime-rain.png`.
Полный ночной рейс и standalone-сборка в этой задаче не проверялись.
