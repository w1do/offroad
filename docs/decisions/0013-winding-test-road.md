# Извилистая тестовая дорога с колеёй

Дата: 31.10.2026.

Для текущей площадки выбрана процедурная полоса из 10 плотных мешей вместо наложенной декали. Гравий вырезан по точным границам, чтобы WheelCollider не встречал невидимую опору под колеёй. Постоянные ключи участков позволяют существующим SoftGroundRuts и TireTrackRenderer удерживать следы в пределах сессии; сохранение на диск не добавлено.

Повторно используются общий VehiclePhysics, SoftGroundRuts, TireTrackRenderer и Game/Living Forest. Отдельной физики Pajero нет. Каждый участок ограничен по длине и разрешению маски, чтобы не обновлять один огромный коллайдер и сохранить различимый протектор. Исходный архив и текстуры сохранены. Детали настройки, результаты короткого прогона и ограничения записаны в SUMMARY.md, раздел «Извилистая дорога и реальные следы».
