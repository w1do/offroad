# Зимний грузовой рейс — Unity-прототип

Сейчас проект содержит Pajero на площадке 100 × 100 м и разработанные общие системы внедорожной машины. Долгосрочная цель — доставка груза по зимней таёжной трассе 100 км.

## С чего начать

Открыть проект в Unity 6000.6.7f1 и сцену `Assets/MountainDrive/MountainPass.unity`.

- [SUMMARY.md](SUMMARY.md) — что сделано, как работает, зачем нужно и что осталось.
- [AGENTS.md](AGENTS.md) — правила разработки и ограничения проекта.
