# Tasks

Порядок намеренный: первый предъявляемый результат — новая оптимизированная графика и выбор пресетов в действующем мире. Пункты 1–4 образуют этот этап; пункты 5–8 завершают весь объём ТЗ, включая Android. Все пункты пока не выполнены. Контракты — в specs/*/spec.md, решения и стартовые числа — в design.md.
